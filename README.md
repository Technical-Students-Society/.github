# Technical Student Society (TSS)

A student-driven technical community built by students, for students.

## About

Technical Student Society (TSS) is a student-led community focused on promoting technical skills through workshops, coding contests, and technical events.

## Activities

- Coding Contests
- Workshops
- Hackathons
- Technical Events

## Tech Stack

- C++
- JavaScript
- React
- HTML & CSS
- Git & GitHub

## Mission

To create a strong technical culture where students can learn, build, and grow together.

Interested in technology? Be part of TSS and start your journey.
