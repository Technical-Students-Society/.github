## 🚀 About TSS

Technical Student Society (TSS) is a student-led technical community focused on building practical skills through real-world experiences.

We organize coding contests, workshops, and technical events to help students grow and explore technology beyond the classroom.

Our goal is to create a strong technical culture where students can **learn, build, and grow together.**
